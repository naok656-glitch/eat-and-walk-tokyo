# ワークフロー:リール1本を作る

流れ: リサーチ → 企画 → 台本 → レビュー → 素材準備 → 編集 → 品質確認 → 投稿 → 分析 → 改善提案

## 「リールを1本作って」と言われたら(28進行管理が実行)

### ステップ0 不足情報を1問ずつ確認
未記入の項目だけ質問する(brand.yamlに値があれば聞かない)。

1. テーマの指定はあるか(なければ06〜07で提案)
2. 紹介する商品・サービスは決まっているか(なければ提案)
3. 尺と本数(初期値: 15〜30秒、1本)
4. 参考台本・参考アカウントはあるか
5. 今回だけのNG条件はあるか
6. 公開予定日

### 差し戻しルール
- 13〜15、22で不合格の場合は、該当の作成担当に差し戻す
- 同じ指摘が2回続いたら、28進行管理が本人に相談する
- 事実確認で未確認が残る場合、その記述を削除するか本人に質問する(推測で埋めない)
