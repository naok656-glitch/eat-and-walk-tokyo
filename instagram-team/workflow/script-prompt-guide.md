# 台本づくりの参考(プロンプトの型)

出典: Taskhub「ChatGPTとずんだもんで台本を作成するプロンプト5選」(2025-07-05)。本人が共有(2026-11-06)。本文は本人がチャットに貼ったものを要約。
担当 08構成・09フック・10台本・13台本レビューが参照する。

## 記事から使う考え方

1. **指示は具体的に書く**。「台本を作って」だけでは平凡になる。次の4つを必ず入れる
   - 誰に向けて(ターゲット)
   - どんな場面か(テーマ・状況)
   - どんな口調・感情か(キャラクター・トーン)
   - 長さと出力の形式
2. **構成を決めてから書く**。ショート動画(30〜60秒)は「導入(問題提起)→展開(解決・魅力)→締め(呼びかけ)」の3段。長尺は「導入→本編(パート分け)→まとめ」
3. **キャラクターを使うなら、口調を明示する**。一人称・語尾・性格を書く。2人の掛け合いなら、それぞれの口調の違いを書いて混ざらないようにする
4. **出力の形式を指定する**。話者名「セリフ」、1セリフ1行、ナレーションは括弧、パートの見出し、など。編集の手間が減る
5. **長いものは分けて作る**。構成 → パートごとの台本、の順に分けて頼む
6. **何度か出し直して、最後は人が直す**。AIの出力は下書き

## このアカウントで気をつけること(記事にない分)

- **事実は必ず確認する**。記事の実行例にも誤りがある(例:千利休を「室町時代」としているが、活躍したのは安土桃山時代。ずんだもんの由来の説明もあいまい)。AIが書いた事実は、出典が取れたものだけ使う(担当14 事実確認)
- **体験談を作らない**。本人が話した内容だけを体験として書く
- **効果効能・健康効果を言い切らない**。記事の例(抹茶の「抗酸化作用」など)のような表現は使わない
- **PR表記**。アフィリエイトの誘導がある回は、キャプション1行目と表紙に「PR」(rules/compliance.md)
- 今のリールは**字幕だけ(ナレーションなし)・約30秒・静止画スライド**。1枚の字幕は短く、画面では3行以内に分ける

## このアカウント用の型(ショート・字幕のみ)

```
#役割
あなたはInstagramリールの台本を書く担当です。

#入力
テーマ:<例:加湿器4方式の違いと選び方>
ターゲット:<例:30〜40代、長く使える物を選んで買いたい人>
目的:<例:保存してもらう / プロフィールのリンクへ>
使える事実:<出典つきの事実を箇条書きで。ここにないことは書かない>

#制約
・尺は約30秒、スライド8枚前後。1枚の字幕は全角30字以内を目安に、画面では3行以内
・構成は「フック(0〜3秒)→結論・選ぶ基準→中身(1枚1ポイント)→まとめ(目的別の早見)→CTA(1つだけ)」
・口調は話し言葉で親しみやすく。誇張・煽り(絶対・最強・必ず など)はしない
・使える事実に書いていないこと、体験談、効果効能の言い切りは書かない
・各字幕に、使った事実の出典番号を付ける

#出力形式
| # | 秒 | 字幕 | 画面 | 出典 |
のあとに、フック案3つ、表紙タイトル案3つ
```

## キャラクターの掛け合いにする場合の型

```
#キャラクター
・A:<名前>。一人称「<僕/私>」、語尾「<〜なのだ など>」、性格<明るく少しおっちょこちょい>
・B:<名前>。一人称「<>」、語尾「<>」、性格<落ち着いて説明する役>
・AとBの口調は混ぜない

#出力形式
【シーン説明】1文
A「…」
B「…」
(1セリフ1行。ナレーションは括弧)
```

※既存キャラクター(ずんだもん等)の声や画像を使う場合は、各キャラクターの利用規約(商用利用・クレジット表記の要否)を先に確認する。
