# プロフィール設定(本人がアプリで入力)

| 項目 | 内容 |
|---|---|
| アイコン | `icon.png`(1080×1080。丸く切り抜かれる前提で作成) |
| 名前 | くらしの買い物ノート|家電の選び方 |
| ユーザーネーム | 本人が作成したもの(未共有) |
| カテゴリ | デジタルクリエイター(またはブロガー) |
| リンク | 空欄(各ASPの規約確認とリンク準備が済むまで入れない) |

## 自己紹介文(版A:リンク準備前、いま使う版)
```
買う前に30秒でわかる「選び方」を図解で🧺
✔ 家電・日用品の違いを比較
✔ 電気代・お手入れもチェック
保存して、買い物の前に見返してね
```

## 自己紹介文(版B:リンク準備後)
版Aの最後に次の2行を足し、リンク欄に楽天ROOMなどのURLを入れる。Amazonの表示文言は運営規約で確認してから入れる(未確認)。
```
おすすめはリンクから(PRを含みます)
```

## 入力手順
1. プロフィール画面で「プロフィールを編集」を押す
2. 「写真を編集」→ `icon.png` を選ぶ
3. 「名前」に上の名前を入れる
4. 「自己紹介」に版Aを貼り付ける
5. 右上の「完了」(またはチェック)を押す
