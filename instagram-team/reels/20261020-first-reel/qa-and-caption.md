## 24 キャプション

### 版A:リンク準備前(いま使う版)
```
加湿器、なんとなく選んでいませんか?

加湿器は大きく4方式。
スチーム式・気化式・超音波式・ハイブリッド式で、電気代・加湿力・お手入れのしやすさが変わります。

▶ 電気代を抑えたい → 気化式
▶ しっかり加湿したい → スチーム式
▶ 手軽に始めたい → 超音波式
▶ バランス重視 → ハイブリッド式

部屋の広さ(適用畳数)もあわせて確認を。
小さな子どもがいる家は、スチーム式の置き場所に注意してください。

※特徴は一般的な傾向です。機種によって異なります。
買う前に見返せるよう、保存しておいてね。

#加湿器 #加湿器の選び方 #家電選び #冬支度 #暮らしの知恵
```

### 版B:リンク準備後(各ASPの規約確認・リンク設定が済んでから)
版Aの1行目の前に「PR」を入れ、最後の行の前に次を追加する。表紙(slide1)にも小さく「PR」を入れて動画を作り直す。
```
方式別のおすすめは、プロフィールのリンクにまとめています。
```

## 23 投稿の手順(本人が行う)
1. スマホに `reel.mp4` を保存する
2. Instagramで「リール」を選び、動画を選ぶ
3. 音源を付ける場合は、Instagram内の音源から選ぶ(音量は小さめ)
4. カバー画像は1枚目(表紙)を選ぶ
5. キャプションは版Aを貼り付ける
6. 投稿したら、投稿日時とURLを教えてください(投稿台帳に記録し、数日後に数値を確認します)
