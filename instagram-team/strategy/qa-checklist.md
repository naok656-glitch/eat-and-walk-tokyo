# 公開前チェック(毎週の制作で、schedule.json に登録する前に必ず通す)

チェックの深さはリスクで変える。
- 通常の回: 制作者(本体)がこの表で自己チェック
- 高リスクの回(健康・安全・お金・具体的な数値や価格・特定商品の推奨を含む): Agent ツールでレビュー役を1人だけ起動し、spec.json・caption.txt・出典を渡して指摘を受ける(3本まとめて1回)

| 観点 | 合格の条件 |
|---|---|
| 事実 | 数値・事実に出典がある。出典が確認できないものは削除した |
| 法令・ルール | 効果効能の断定なし、体験談の捏造なし、商品紹介の回は「PR」を1行目に |
| 視聴者目線 | 1枚目だけで「自分に関係ある」と分かる。1枚目の文字は20字以内 |
| 構成 | 1枚の文字が読み切れる量(1枚4秒なら40字以内) |
| 導線 | まとめページに関連商品がある回だけ「プロフィールのリンクから」と書く(ない回は書かない) |
| 重複 | 直近の batch と同じテーマ・同じフックでない |
| 技術 | 画像のはみ出し・誤字なし、動画の尺が spec の秒数と一致 |
不合格の項目が残る回は、schedule.json に登録しない。
