# 収益化の段階と、今いちばん見る指標(毎週の制作の最初に読む)

数値はすべて `reports/` の実測値で判断する。しきい値は初期の仮説で、データがたまったら見直す(見直したら experiments.md に記録)。

| 段階 | 判定の目安(直近4週の合計) | 最優先で改善するもの | 主な指標 |
|---|---|---|---|
| 1. 届いていない | リーチが1本あたり平均300未満 | 企画(テーマ)とフック(1〜2枚目) | リーチ、再生、平均視聴秒 |
| 2. 見られるが残らない | リーチはあるが、平均視聴が尺の25%未満 | 構成・テンポ・1枚目の見せ方 | 平均視聴秒、保存率 |
| 3. 残るが動かない | 保存率1%以上だが、プロフィールのリンクタップが月10未満 | CTA(行動の呼びかけ)とキャプションの導線 | リンクタップ(profile_links_taps) |
| 4. 動くが買われない | リンクタップ月10以上で、楽天の成果が0 | まとめページの商品選定・見せ方・価格帯 | 楽天のクリック・成果(本人の管理画面/週次戦略会議) |
| 5. 成果が出ている | 成果が継続 | 当たり型の再現と量の調整 | 成果件数、報酬、1本あたり報酬 |

## 判断のルール
- 投稿が合計9本未満のうちは、段階を仮置きにして、テーマの幅を広げて検証する(1本の結果で断定しない)
- 変えるのは1回に1〜2か所だけ(何が効いたか分かるように)
- 成果が出ている型は、根拠なく変えない
- 2週続けて全く改善しない施策は、やめて別の仮説に切り替える

## 取得できるデータ(2026-10-21確認)
- Instagram API で取得可: 再生、リーチ、保存、シェア、いいね、コメント、平均視聴時間、アカウントのリンクタップ(profile_links_taps)
- 取得できない: まとめページのクリック数(GitHub Pagesに計測なし)、楽天の成果(公式APIなし。本人の管理画面か、既存の週次戦略会議のChrome確認)
