# ブログ(くらしの買い物ノート)クラウド自動運用

本人のアカウントスキル「kurashi-note-routine」の方針・文体・ルールを守る。画面操作ではなく、はてなブログのAPIで保存・公開する。
2026-10-21 本人決定: 比較・まとめ記事はクラウドで自動公開する(パソコン不要・昼に公開)。体験談の記事(Gmailの【体験メモ】)は、従来どおりパソコンの「夜間ブログ下準備」が下書きを作り、本人が公開する。

## 実行
- 毎週 月・水・金 11:52(日本時間)に定期実行。1回に1本
- 公開の条件(すべて満たすときだけ `--publish`。1つでも欠けたら下書きで保存して報告):
  1. 体験談を含まない(「使った」「着た」など本人の体験の記述がない。比較・まとめ・選び方の記事)
  2. 下の公開前チェックで重大な指摘がゼロ
  3. 価格・レビュー数は、この回に楽天APIで取得した値だけ(確認日つき)
  4. 冒頭のPR表記、末尾のアソシエイト・楽天アフィリエイト参加の一文、リンクの rel 属性がある

## 手順
1. 現状確認: `python3 blog-team/tools/hatena_draft.py list` で既存記事を見て、テーマの重複を避ける
2. テーマ: 方針の柱(アウトドアウェアの比較・選び方、ガジェットの比較、季節ネタ=ブラックフライデー・楽天スーパーSALE・ふるさと納税12/31締切)から1本。検索されそうな具体的な語(「商品名 比較」「選び方」など)をタイトルの前半に入れる(32文字前後)
3. 商品情報: 楽天APIで価格・レビュー数・画像・アフィリエイトリンクを取る(`instagram-team/tools/rakuten_picks.py` の search を流用。商品名の必須語・除外語で取り違えを防ぐ)。楽天リンクはAPIが返す affiliateUrl を使う。Amazonは検索リンク https://www.amazon.co.jp/s?k=(URLエンコードした検索語)&tag=kurashinote061-22 を並べる
4. 本文: 1,500〜3,000字のHTML。冒頭に <p style="font-size:12px;color:#888;">※本記事はアフィリエイト広告を利用しています</p>。末尾に「Amazonのアソシエイトとして、くらしの買い物ノートは適格販売により収入を得ています。楽天アフィリエイトに参加しています。」。リンクは rel="nofollow sponsored noopener"。話し言葉、見出しに絵文字、スマホで読みやすく。サイズ感に触れるときは「身長180cm/体重75kg」を添える
5. 公開前チェック: Agent ツールでレビュー役を1人だけ起動し、本文ファイルと上のルールを渡して、事実(価格・出典・型番)/読者目線(知りたいことがあるか・買う決め手になるか)/編集(AIっぽい硬さ・詰め込み)/ルール(PR・rel・ステマ・効果効能・個人名)の4観点で指摘させる。重大な指摘は直す。直せなければ下書きにする
6. 保存: 条件を満たせば `python3 blog-team/tools/hatena_draft.py post <file> --title "…" --category … --publish`、満たさなければ `--publish` なし
7. 記録: `blog-team/drafts/YYYYMMDD-<slug>.html` に本文を保存し、changelog に1行追記してコミット・push
8. 報告: 公開したか下書きにしたか、タイトル、記事URL(公開時)、チェックで直した点を短く報告する(通知で本人に届く)

## ルール(kurashi-note-routine より)
- 使っていない商品を「使った」と書かない。体験談を作らない
- 個人名を記事に入れない。本人の購入金額は書かない
- 価格・星・レビュー数は、その場で確認した実際の数字だけ(確認日を添える)
- 公開済み記事の更新はしない(本人が頼んだときだけ)
- 有料ツール・広告出稿はしない
